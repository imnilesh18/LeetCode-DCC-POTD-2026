## 📝 Problem Statement

You are given a **1-indexed** integer array `nums` of length `n`.

An element `nums[i]` of `nums` is called **special** if `i` divides `n`, i.e., `n % i == 0`.

Return *the sum of the squares of all special elements of `nums`*.

---

## ⛔ Constraints

- `1 <= nums.length == n <= 50`
- `1 <= nums[i] <= 50`

## 🛠️ Approach

There are two primary ways to solve this problem based on how we identify the divisors of the array length `n`:

1.  **Brute Force (Simulation):** We can simply iterate through all indices from `1` to `n`. For each index, we check if it perfectly divides `n`. If it does, we take the corresponding element (at 0-based index `i-1`), square it, and add it to our running total.
2.  **Optimized Divisor Search:** Mathematically, divisors always occur in pairs. If `i` is a divisor of `n`, then `n/i` is also a divisor. Therefore, instead of looping all the way up to `n`, we only need to iterate up to the square root of `n` (`sqrt(n)`). For every divisor `i` we find, we immediately process both `nums[i-1]` and `nums[n/i - 1]`.

## 💻 Solution Code

### Brute-force Solution (C++)

```cpp
// Intuition: We can find the sum of squares of special elements by checking every 1-based index to see if it divides the array's total length.
// Approach: 
// 1. Retrieve the size of the array `n`.
// 2. Initialize a `result` variable to accumulate the sum of squares.
// 3. Iterate through the array using a 0-based index `i`.
// 4. Check if the 1-based index `(i + 1)` is a divisor of `n`.
// 5. If it is, square the element `nums[i]` and add it to `result`.
// 6. Return the accumulated sum.
// Time Complexity: O(n) where n is the number of elements in the array. We iterate through the array exactly once.
// Space Complexity: O(1) as we only use a few primitive variables for tracking size and sum.
class Solution {
public:
    int sumOfSquares(vector<int>& nums) {
        int n = nums.size();
        int result = 0;
        
        for (int i = 0; i < n; ++i) {
            // Check if 1-based index is a factor of n
            if (n % (i + 1) == 0) {
                result += (nums[i] * nums[i]);
            }
        }
        return result;
    }
};

/*
*
* Dry Run
* Input: nums = [1, 2, 3, 4]
* Initialize: n = 4, result = 0
* i = 0: index = 1. 4 % 1 == 0 -> result += 1*1 = 1
* i = 1: index = 2. 4 % 2 == 0 -> result += 2*2 = 5
* i = 2: index = 3. 4 % 3 != 0 -> result remains 5
* i = 3: index = 4. 4 % 4 == 0 -> result += 4*4 = 21
* Output: 21
*
*/
```

### Optimized Solution (C++)

```cpp
// Intuition: Since we only care about factors of `n`, we can find them much faster. Factors come in pairs, so we only need to check up to the square root of `n`.
// Approach:
// 1. Retrieve the size of the array `n`.
// 2. Loop `i` from 1 up to `sqrt(n)`.
// 3. If `i` divides `n` evenly, it means `i` is a factor. We add the square of `nums[i - 1]` to our result.
// 4. We then compute the paired factor `n / i`. If `n / i` is distinct from `i` (meaning `n` isn't a perfect square of `i`), we also add the square of `nums[n / i - 1]`.
// 5. Return the total `result`.
// Time Complexity: O(sqrt(n)) because the loop strictly terminates when i * i exceeds n.
// Space Complexity: O(1) since we compute the sum strictly in-place with primitive variables.
class Solution {
public:
    int sumOfSquares(vector<int>& nums) {
        int n = nums.size();
        int result = 0;

        for (int i = 1; i * i <= n; ++i) {
            if (n % i == 0) {
                // i is a factor of n, add square of nums[i-1]
                result += nums[i - 1] * nums[i - 1];

                // If not a perfect square, process the mirrored factor
                if (i * i != n) { 
                    // n/i is the other factor, add square of nums[n/i-1]
                    result += nums[n / i - 1] * nums[n / i - 1];
                }
            }
        }
        return result;
    }
};

/*
*
* Dry Run
* Input: nums = [2, 7, 1, 19, 18, 3]
* Initialize: n = 6, result = 0
* i = 1: 6 % 1 == 0 -> result += nums[0]*nums[0] (2*2) = 4. 
*        1*1 != 6, so partner factor is 6/1 = 6 -> result += nums[5]*nums[5] (3*3) = 13.
* i = 2: 6 % 2 == 0 -> result += nums[1]*nums[1] (7*7) = 62.
*        2*2 != 6, so partner factor is 6/2 = 3 -> result += nums[2]*nums[2] (1*1) = 63.
* i = 3: 3*3 = 9 > 6. Loop terminates.
* Output: 63
*
*/
```

## 🧠 Key Insights
- **1-based Indexing Awareness:** LeetCode problems often use 0-based indexing for vectors, but this problem explicitly references 1-based indices to determine standard mathematical division. We must map `i` to `i-1` or strictly track an index `1 to n`.
- **Mathematical Optimization:** The key to optimizing array loops that involve factors/divisors is the integer limit of `sqrt(n)`. This brings an $O(n)$ solution down to $O(\sqrt{n})$, heavily improving runtime for large $n$.
