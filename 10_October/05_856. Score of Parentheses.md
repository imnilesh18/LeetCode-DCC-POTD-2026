# 856. Score of Parentheses

**Difficulty:** Medium 🟡  
**Problem Link:** [Score of Parentheses](https://leetcode.com/problems/score-of-parentheses/description/)  
**Tags:** `String`, `Stack`, `Bracket Sequences`  

---

## 📖 Problem Statement

Given a balanced parentheses string `s`, return the score of the string.

The score of a balanced parentheses string is based on the following rules:
- `"()"` has score `1`.
- `AB` has score `A + B`, where `A` and `B` are balanced parentheses strings.
- `(A)` has score `2 * A`, where `A` is a balanced parentheses string.

---

## 💡 Examples

| Example | Input | Output | Explanation |
| :--- | :--- | :--- | :--- |
| **1** | `s = "()"` | `1` | A simple pair evaluates to 1. |
| **2** | `s = "(())"` | `2` | `()` is 1, and it is enclosed by another pair, so `2 * 1 = 2`. |
| **3** | `s = "()()"` | `2` | Two adjacent pairs: `1 + 1 = 2`. |

---

## ⚙️ Constraints

- `2 <= s.length <= 50`
- `s` consists of only `'('` and `')'`.
- `s` is a guaranteed **balanced** parentheses string.

---

## 🧠 Approach & Explanation

Based on the rules provided, we can break down the evaluation of the string using two robust methods:

### Approach 1: Using a Stack / Vector
To calculate the nested scores, we can maintain the current score in a variable. Whenever we encounter an opening bracket `(`, it means we are entering a new, deeper layer of parentheses. We must save our current score by pushing it into a vector (acting as a stack) and reset our current score to 0 to evaluate the inner contents. 

When we encounter a closing bracket `)`, we are completing a layer. We pop the last saved score from our vector and update our total score. If the pair was an empty `()`, the inner score is 1. If it contained nested parentheses, the inner score is multiplied by 2. We then add this evaluated inner score to the popped outer score.

### Approach 2: Tracking Depth (Optimized)
Notice a mathematical pattern: an innermost simple pair `()` contributes exactly $2^{depth}$ to the total score, where `depth` is the number of layers enclosing it. Instead of maintaining a stack, we can simply track the current depth. 

Every time we see `(`, we increment the depth. Every time we see `)`, we decrement it. If we encounter an innermost pair (identified by a `)` immediately following a `(`), we calculate its contribution as $2^{depth}$ and add it directly to our total score. Outer closing brackets simply reduce the depth without adding to the score, as their multiplier effect has already been applied.

## 💻 Solution Code

### Approach 1: Stack / Vector (O(N) Space)

```cpp
// Intuition: We need to calculate the score based on the depth and structure of parentheses. Using a vector as a stack helps keep track of the score of the outer layers while we calculate the score of the inner layers.
// Approach: 
// 1. Traverse the string. Keep a `score` variable initialized to 0.
// 2. On '(', push the current score to the vector and reset `score = 0` for the new inner layer.
// 3. On ')', if the previous character was '(', it's a simple "()", so the new score is the previous outer score + 1.
// 4. If the previous character was ')', it's a nested structure, so the new score is outer score + 2 * inner score.
// 5. Pop the last score from the vector to merge layers.
// Time Complexity: O(n) where n is the length of the string. We iterate through the string exactly once.
// Space Complexity: O(n) in the worst case (e.g., "(((())))") where the vector stores n/2 elements.

class Solution {
public:
    int scoreOfParentheses(string s) {
        int n = s.length();
        vector<int> vec;

        int score = 0;

        for (int i = 0; i < n; i++) {
            char ch = s[i];
            if (ch == '(') {
                vec.push_back(score); // Save outer score before entering a new nested layer
                score = 0;            // Reset current score for the new inner layer
            } else {
                if (s[i-1] == '(') { // we found inner most "()" -> +1 point
                    score = vec.back() + 1;
                } else {
                    // had content inside -> double it
                    score = vec.back() + (2 * score);
                }
                vec.pop_back(); // Merge completed inner layer with the outer layer
            }
        }
        return score;
    }
};

/*
*
* Dry Run
* Input: s = "(())"
* i = 0, s[0] = '(': vec = [0], score = 0
* i = 1, s[1] = '(': vec = [0, 0], score = 0
* i = 2, s[2] = ')': s[1] == '(' -> score = vec.back() + 1 = 0 + 1 = 1. pop_back() -> vec = [0]
* i = 3, s[3] = ')': s[2] == ')' -> score = vec.back() + 2 * score = 0 + 2 * 1 = 2. pop_back() -> vec = []
* Final Return: 2
*
*/
```

### Approach 2: Calculating from Depth (O(1) Space)

```cpp
// Intuition: Every innermost "()" contributes exactly 2^depth to the final score, where `depth` is the number of outer parentheses enclosing it. We can track the depth and add 2^depth whenever we find an innermost "()".
// Approach: 
// 1. Maintain `score` and `depth` variables initialized to 0.
// 2. Iterate through the string. On '(', increment `depth`.
// 3. On ')', decrement `depth`.
// 4. Check if the current ')' forms an innermost pair (i.e., previous char was '(').
// 5. If yes, add 2^depth to the total score using bitwise left shift `(1 << depth)`.
// Time Complexity: O(n) where n is the length of the string. Single pass.
// Space Complexity: O(1) as we are only using two integer variables regardless of input size.

class Solution {
public:
    int scoreOfParentheses(string s) {
        int score = 0;
        int depth = 0;

        for (int i = 0; i < (int)s.size(); i++) {
            if (s[i] == '(') {
                depth++; // Entering a deeper layer
            } else {
                depth--; // Exiting a layer
                if (s[i - 1] == '(') {
                    score += (1 << depth);  // i.e. 2^depth added for every innermost pair
                }
            }
        }
        return score;
    }
};

/*
*
* Dry Run
* Input: s = "(()(()))"
* i=0, '(': depth = 1
* i=1, '(': depth = 2
* i=2, ')': depth = 1, s[1] == '(' -> score += (1 << 1) -> score = 2
* i=3, '(': depth = 2
* i=4, '(': depth = 3
* i=5, ')': depth = 2, s[4] == '(' -> score += (1 << 2) -> score = 2 + 4 = 6
* i=6, ')': depth = 1, s[5] != '(' -> score unchanged
* i=7, ')': depth = 0, s[6] != '(' -> score unchanged
* Final Return: 6
*
*/
```

## 📌 Notes
- Recognizing mathematical properties (like distribution: `2 * (1 + 1) = 2 + 2`) can often turn an $O(N)$ space stack problem into an $O(1)$ space counting problem. 
- The bitwise left-shift operator `1 << depth` is computationally highly efficient for calculating powers of two ($2^{depth}$).

## 🚀 Key Insights
The most elegant aspect of Approach 2 is realizing that we don't need to actually perform the multiplication dynamically from the inside out. By knowing exactly how deep an innermost `()` is buried, we can directly compute its final scaled contribution to the total score right when we encounter it.
