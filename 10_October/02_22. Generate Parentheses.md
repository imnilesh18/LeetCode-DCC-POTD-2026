## 📜 Problem Statement

Given `n` pairs of parentheses, write a function to generate all combinations of well-formed parentheses.

## 🚦 Constraints

- `1 <= n <= 8`

## 💡 Examples

| Example | Input | Output |
| :--- | :--- | :--- |
| **Example 1** | `n = 3` | `["((()))","(()())","(())()","()(())","()()()"]` |
| **Example 2** | `n = 1` | `["()"]` |

---

## 🧠 Explanation & Approach

To generate all valid combinations of parentheses, we can imagine building the sequence character by character. At any given point, we only have two choices: append an open parenthesis `(` or append a closed parenthesis `)`. 

However, to ensure the sequence remains "well-formed", we must adhere to two strict rules during generation:
1. **Adding an Open Parenthesis:** We can add `(` as long as we haven't used all `n` open parentheses.
2. **Adding a Closed Parenthesis:** We can add `)` strictly if the number of closed parentheses currently used is less than the number of open parentheses used (this ensures every closed bracket matches a preceding open bracket).

By implementing a **Backtracking** approach, we can explore all valid paths. When our current string reaches the length of `2 * n` (since `n` pairs mean `2n` total characters), we know we've successfully formed a valid sequence, which we can then add to our result array.

## 💻 Solution Code

### Brute Force Solution

```cpp
// Intuition: Generate all possible combinations of length 2n consisting of '(' and ')', and then filter out the invalid sequences.
// Approach: 
// 1. Use recursion to generate every possible string of length 2n.
// 2. Use a helper function to validate if the generated string has balanced parentheses.
// 3. If valid, add it to the result array.
// Time Complexity: O(2^(2n) * n) - We generate 2^(2n) combinations and validate each in O(n) time.
// Space Complexity: O(n) - The maximum depth of the recursion tree is 2n.

class BruteForceSolution {
public:
    bool isValid(string& s) {
        int balance = 0;
        for(char c : s) {
            if(c == '(') balance++;
            else balance--;
            if(balance < 0) return false; // More close brackets than open
        }
        return balance == 0;
    }

    void generateAll(vector<string>& result, string& current, int n) {
        // Base case: sequence is fully formed
        if (current.length() == 2 * n) {
            if (isValid(current)) {
                result.push_back(current);
            }
            return;
        }
        
        current.push_back('(');
        generateAll(result, current, n);
        current.pop_back(); // Backtrack

        current.push_back(')');
        generateAll(result, current, n);
        current.pop_back(); // Backtrack
    }

    vector<string> generateParenthesis(int n) {
        vector<string> result;
        string current = "";
        generateAll(result, current, n);
        return result;
    }
};

/*
*
* Dry Run
* n = 1
* generateAll("", 1)
*  |-- add '(' -> current: "("
*       |-- add '(' -> "((" (Filtered out by isValid)
*       |-- add ')' -> "()" (Valid, added to result)
*  |-- add ')' -> current: ")"
*       |-- add '(' -> ")(" (Filtered out by isValid)
*       |-- add ')' -> "))" (Filtered out by isValid)
* Result: ["()"]
*
*/

```

### Optimized Solution (Backtracking)

```cpp
// Intuition: Instead of generating all permutations and filtering them, we can strategically build only the valid sequences by tracking the counts of open and closed parentheses.
// Approach: 
// 1. Maintain counters for `open_count` and `close_count`.
// 2. Append '(' if `open_count < n`. Make a recursive call, then backtrack.
// 3. Append ')' if `close_count < open_count`. Make a recursive call, then backtrack.
// 4. When the string length equals 2*n, a valid sequence is formed.
// Time Complexity: O(4^n / sqrt(n)) - The number of valid combinations is bounded by the nth Catalan number.
// Space Complexity: O(n) - The recursion stack will reach a maximum depth of 2n.

class Solution {
public:
    void backtrack(vector<string>& result, string& current, int open_count, int close_count, int n) {
        // Base case: if the current string has reached the maximum length (2 * n)
        if (current.length() == n * 2) {
            result.push_back(current);
            return;
        }
        
        // If we haven't used all our open parentheses, we can add one
        if (open_count < n) {
            current.push_back('(');
            backtrack(result, current, open_count + 1, close_count, n);
            current.pop_back(); // Backtrack
        }
        
        // If we have more open parentheses than close parentheses, we can close one
        if (close_count < open_count) {
            current.push_back(')');
            backtrack(result, current, open_count, close_count + 1, n);
            current.pop_back(); // Backtrack
        }
    }
    vector<string> generateParenthesis(int n) {
        vector<string> result;
        string current = "";
        backtrack(result, current, 0, 0, n);
        return result;
    }
};

/*
*
* Dry Run
* n = 2
* backtrack("", 0, 0, 2)
*  |-- open (0) < n (2): add '(', call backtrack("(", 1, 0, 2)
*       |-- open (1) < n (2): add '(', call backtrack("((", 2, 0, 2)
*            |-- close (0) < open (2): add ')', call backtrack("(()", 2, 1, 2)
*                 |-- close (1) < open (2): add ')', call backtrack("(())", 2, 2, 2)
*                      -> BASE CASE HIT: length == 4. Add "(())" to result.
*       |-- close (0) < open (1): add ')', call backtrack("()", 1, 1, 2)
*            |-- open (1) < n (2): add '(', call backtrack("()(", 2, 1, 2)
*                 |-- close (1) < open (2): add ')', call backtrack("()()", 2, 2, 2)
*                      -> BASE CASE HIT: length == 4. Add "()()" to result.
* Result: ["(())", "()()"]
*
*/

```

## 🎯 Key Insights

* **Catalan Numbers:** The total number of valid bracket combinations for `n` pairs is exactly the `n`-th Catalan number.
* **Pruning:** The optimized solution essentially prunes the decision tree of the brute force approach. It strictly prevents branching into states that will inevitably become invalid (like starting a sequence with a closing bracket).
