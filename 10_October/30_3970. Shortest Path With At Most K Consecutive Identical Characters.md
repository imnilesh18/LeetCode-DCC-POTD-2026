# 3970. Shortest Path With At Most K Consecutive Identical Characters

**Problem Link:** [Shortest Path With At Most K Consecutive Identical Characters](https://leetcode.com/problems/shortest-path-with-at-most-k-consecutive-identical-characters/)
**Difficulty:** Medium
**Tags:** `String`, `Graph Theory`, `Heap (Priority Queue)`, `Shortest Path`

---

## 📝 Problem Statement

You are given an integer `n` representing the number of nodes in a directed weighted graph, numbered from `0` to `n - 1`. This is represented by a 2D integer array `edges`, where `edges[i] = [ui, vi, wi]` represents a directed edge from node `ui` to node `vi` with weight `wi`.

You are also given a string `labels` of length `n`, where `labels[i]` is the character assigned to node `i`, and an integer `k`.

Return the *minimum total edge weight* of a path from node `0` to node `n - 1` such that the concatenation of the labels of the nodes along the path contains **at most** `k` consecutive identical characters. If no valid path exists, return `-1`.

### Constraints:
- `1 <= n == labels.length <= 5 * 10^4`
- `0 <= edges.length <= 5 * 10^4`
- `edges[i] == [ui, vi, wi]`
- `0 <= ui, vi <= n - 1`
- `ui != vi`
- `1 <= wi <= 10^4`
- `labels` consists of lowercase English letters
- `1 <= k <= 50`

## 🧠 Approach & Key Insights

To find the shortest path in a weighted graph with positive weights, **Dijkstra's Algorithm** is the standard approach. However, this problem introduces a constraint based on the state of the path (the consecutive identical character count).

1. **State Tracking:** In standard Dijkstra, we track the shortest distance to a `node`. Here, a path with a sub-optimal distance but a smaller consecutive character count might be the only way to reach the destination later. Thus, our state must be represented as `[node][count]`.
2. **2D Distance Array:** We maintain a 2D array `result[node][count]` storing the minimum cost to reach a `node` with exactly `count` consecutive identical characters ending at this node.
3. **Modified Dijkstra:** 
   - Our Min-Heap will store `{distance, node, count}`.
   - When traversing to a neighbor `v` from `u`:
     - If `labels[v] == labels[u]`, the new consecutive count is `count + 1`.
     - If `labels[v] != labels[u]`, the new consecutive count resets to `1`.
   - If the new count exceeds `k`, we safely prune (skip) this path.
   - If the new calculated distance is less than `result[v][newCount]`, we update it and push the new state to the Min-Heap.

## 💻 Solution Code

```cpp
// Intuition: The problem requires the shortest path in a weighted directed graph, making Dijkstra's Algorithm the perfect fit. Since we have a strict constraint on consecutive identical characters, we must expand our state to track both the current node and the current consecutive character count.
// Approach: We modify Dijkstra's by using a 2D distance array `result[node][count]`. The priority queue stores `{distance, node, current_consecutive_count}`. For every neighbor, we calculate the new count. If it exceeds `k`, we prune it. Otherwise, we relax the edge if a shorter path to that specific `[node][count]` state is found.
// Time Complexity: O(E*K * log(N*K)), where N is the number of nodes, E is the number of edges, and K is the max consecutive character limit. In the worst case, each node can be visited K times.
// Space Complexity: O(N*K + E), to store the graph adjacency list and the 2D distance array of size N x K.

class Solution {
public:
    // Custom tuple definition for Priority Queue: {distance, node, count}
    typedef tuple<int, int, int> T; 

    int shortestPath(int n, vector<vector<int>>& edges, string labels, int k) {
        // Build the adjacency list for the directed graph
        unordered_map<int, vector<vector<int>>> adj;
        for (auto &edge : edges) {
            int u  = edge[0];
            int v  = edge[1];
            int wt = edge[2];
            adj[u].push_back({v, wt});
        }

        // result[node][count] = min cost to reach node with 'count' consecutive identical chars
        vector<vector<int>> result(n, vector<int>(k + 1, INT_MAX));

        // Min-heap to always expand the shortest path first
        priority_queue<T, vector<T>, greater<T>> pq;

        // Base case: Starting at node 0 with its own character (count = 1)
        result[0][1] = 0;
        pq.push({0, 0, 1});

        while (!pq.empty()) {
            auto [d, node, count] = pq.top();
            pq.pop();

            // Skip if we already found a shorter path for this exact state
            if (d > result[node][count]) 
                continue;

            // If we reach the target node, since it's a min-heap, this is the guaranteed shortest path
            if (node == n - 1) 
                return d;

            // Traverse all outgoing edges from the current node
            for (auto &vec : adj[node]) {
                int adjNode = vec[0];
                int wt      = vec[1];

                // Determine the new consecutive identical character count
                int newCount = (labels[adjNode] == labels[node]) ? count + 1 : 1;
                
                // Prune paths that violate the constraint
                if (newCount > k) 
                    continue;

                // Edge relaxation
                int newDist = d + wt;
                if (newDist < result[adjNode][newCount]) {
                    result[adjNode][newCount] = newDist;
                    pq.push({newDist, adjNode, newCount});
                }
            }
        }

        return -1; // Return -1 if no valid path reaches the destination
    }
};

/*
*
* Dry Run
* Input: n = 3, edges = [[0,1,1],[1,2,1],[0,2,3]], labels = "aab", k = 1
*
* 1. Initialize: result array with INT_MAX. pq = {(0, 0, 1)}
* 2. Pop (0, 0, 1). node=0, dist=0, count=1 ('a').
*    - Neighbor 1: wt=1. labels[1]('a') == labels[0]('a') -> newCount = 2. 2 > k (1). Pruned.
*    - Neighbor 2: wt=3. labels[2]('b') != labels[0]('a') -> newCount = 1. 1 <= k. 
*      newDist = 3 < INT_MAX. result[2][1] = 3. pq = {(3, 2, 1)}
* 3. Pop (3, 2, 1). node=2, dist=3, count=1 ('b').
*    - node (2) == n - 1 (2). Return 3.
* 
* Output: 3
*
*/
```
