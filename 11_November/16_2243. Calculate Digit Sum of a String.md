## 📋 Problem Statement

You are given a string `s` consisting of digits and an integer `k`.

A **round** can be completed if the length of `s` is greater than `k`. In one round, perform the following steps:

1. **Divide** `s` into consecutive groups of size `k` such that the first `k` characters are in the first group, the next `k` characters are in the second group, and so on. *(Note: The size of the last group can be smaller than `k`.)*
2. **Replace** each group of `s` with a string representing the sum of all its digits. For example, `"346"` is replaced with `"13"` because $3 + 4 + 6 = 13$.
3. **Merge** consecutive groups together to form a new string. If the length of the newly formed string is greater than `k`, repeat from step 1.

Return `s` after all rounds have been completed.

🔗 **Problem Link:** [2243. Calculate Digit Sum of a String — LeetCode](https://leetcode.com/problems/calculate-digit-sum-of-a-string/description/)

---

## 🔒 Constraints

- $1 \le \text{s.length} \le 100$
- $2 \le k \le 100$
- `s` consists of digits only (`'0'` through `'9'`).

## 🧠 Approach

The problem directly describes a multi-round **string simulation** process. Because the constraints are small ($\text{s.length} \le 100$ and $k \ge 2$), simulating each round iteratively until the stopping condition (`s.length() <= k`) is reached is both clean and optimal.

### Step-by-Step Breakdown

1. **Stopping Condition (`while (s.length() > k)`):**
   - Continue executing rounds strictly while the current string length exceeds `k`. Once `s.length() <= k`, no further rounds can be performed.
2. **Initialize Round Buffer (`nextStr`):**
   - Create an empty string `nextStr` at the start of each round to accumulate the stringified digit sums of every group.
3. **Chunk Traversal (`for (int i = 0; i < n; i += k)`):**
   - Jump across the string in increments of `k`. Each index `i` marks the starting boundary of a new group.
4. **Safe Group Boundary & Digit Accumulation (`j < min(i + k, n)`):**
   - For the last group in the string, there may be fewer than `k` characters remaining. Clamping the inner loop's upper bound with `min(i + k, n)` avoids out-of-bounds access without needing special edge-case branching.
   - Convert each character digit to its numeric value via ASCII offset subtraction (`s[j] - '0'`) and accumulate it into `sum`.
5. **Append & Move (`s = move(nextStr)`):**
   - Convert `sum` back into its string representation using `to_string(sum)` and append it to `nextStr`.
   - After all groups in the current round are processed, transfer ownership of `nextStr` into `s` using `std::move(nextStr)` to avoid unnecessary deep string copies.

## 💻 Solution Code

### 1. Brute Force (Recursive Substring Slicing)

```cpp
// Intuition: Recursively slice the string into substrings of length k, sum the digits of each slice, and repeat on the concatenated result until length <= k.
// Approach: Base case returns s when s.length() <= k. Otherwise, extract each group with substr(i, k), compute its digit sum, build nextStr, and recurse.
// Time Complexity: O(n), as total characters processed across all shrinking recursive rounds form a convergent geometric series.
// Space Complexity: O(n), due to recursion call stack depth and temporary substring allocations created by substr().
class Solution {
public:
    string digitSum(string s, int k) {
        if (s.length() <= k) { // Base case: no more rounds needed
            return s;
        }

        string nextStr = ""; // Accumulates group sums for this round

        for (int i = 0; i < (int)s.length(); i += k) { // Step through string in chunks of k
            string group = s.substr(i, k); // Allocate substring for current group
            int sum = 0; // Digit sum for the sliced group

            for (char ch : group) { // Sum every character digit in the slice
                sum += ch - '0';
            }

            nextStr += to_string(sum); // Append stringified sum
        }

        return digitSum(nextStr, k); // Recurse for the next round
    }
};

/*
*
* Dry Run
*
* Input: s = "11111222223", k = 3
*
* Call 1: s = "11111222223", length = 11 > 3
*   i = 0: group = "111" -> sum = 3 -> nextStr = "3"
*   i = 3: group = "112" -> sum = 4 -> nextStr = "34"
*   i = 6: group = "222" -> sum = 6 -> nextStr = "346"
*   i = 9: group = "23"  -> sum = 5 -> nextStr = "3465"
*   Recurse with digitSum("3465", 3)
*
* Call 2: s = "3465", length = 4 > 3
*   i = 0: group = "346" -> sum = 13 -> nextStr = "13"
*   i = 3: group = "5"   -> sum = 5  -> nextStr = "135"
*   Recurse with digitSum("135", 3)
*
* Call 3: s = "135", length = 3 <= 3
*   Base case reached -> returns "135"
*
*/
```

### 2. Optimized (Iterative In-Place Index Grouping with Move Semantics)

```cpp
// Intuition: Repeatedly group the string into chunks of size k, sum their digits, and replace the string until its length is at most k.
// Approach: Use a while loop while s.length() > k. In each round, iterate in steps of k, sum digits from i to min(i+k, n) - 1, append to_string(sum) to nextStr, and move nextStr into s.
// Time Complexity: O(n), where n is the initial length of s (each round reduces the string length geometrically until length <= k).
// Space Complexity: O(n), used to store the intermediate string nextStr during each simulation round.
class Solution {
public:
    string digitSum(string s, int k) {
        while(s.length() > k) { // Continue rounds until string length is at most k
            string nextStr; // Stores the newly formed string for the current round

            int n = s.length(); // Current length of the string

            for(int i = 0; i < n; i += k) { // Process consecutive groups of size k
                int sum = 0; // Accumulate digit sum for the current group
                for(int j = i; j < min(i+k, n); j++) { // Safely bound the last group to n
                    sum += s[j]-'0'; // Convert character digit to integer and add
                }
                nextStr += to_string(sum); // Append group sum as string
            }

            s = move(nextStr); //avoids copy by transferring ownership of nextStr to s
        }

        return s; // Return final reduced string
    }
};

/*
*
* Dry Run
*
* Input: s = "11111222223", k = 3
*
* Round 1: s.length() = 11 > 3
*   n = 11, nextStr = ""
*   i = 0: j from 0 to 2 ("111") -> sum = 1 + 1 + 1 = 3 -> nextStr = "3"
*   i = 3: j from 3 to 5 ("112") -> sum = 1 + 1 + 2 = 4 -> nextStr = "34"
*   i = 6: j from 6 to 8 ("222") -> sum = 2 + 2 + 2 = 6 -> nextStr = "346"
*   i = 9: j from 9 to 10 ("23") -> sum = 2 + 3 = 5 -> nextStr = "3465"
*   s = move(nextStr) -> s = "3465"
*
* Round 2: s.length() = 4 > 3
*   n = 4, nextStr = ""
*   i = 0: j from 0 to 2 ("346") -> sum = 3 + 4 + 6 = 13 -> nextStr = "13"
*   i = 3: j from 3 to 3 ("5")   -> sum = 5 -> nextStr = "135"
*   s = move(nextStr) -> s = "135"
*
* Termination: s.length() = 3 <= 3 -> loop ends
* Output: "135"
*
*/
```

## 📝 Notes

- **Why `k >= 2` Guarantees Termination:**
  - Even in the worst case where every digit is `'9'`, a group of $k$ digits has a maximum sum of $9k$, which has $\lfloor \log_{10}(9k) \rfloor + 1$ digits.
  - For $k = 2$, the maximum group sum is $9 + 9 = 18$ ($2$ digits), which shrinks any odd-length string (`length >= 3`) immediately (e.g., `"999"` $\rightarrow$ `"189"` $\rightarrow$ `"99"`).
  - For all $k \ge 3$, $\lfloor \log_{10}(9k) \rfloor + 1 < k$, meaning every single full group strictly decreases in character length during each round.
- **Zero-Allocation Group Scanning:**
  - Instead of calling `s.substr(i, k)` inside the loop, indexing directly from `j = i` up to `min(i + k, n)` avoids allocating temporary `std::string` objects for every chunk.
- **Leading Zeros Preservation:**
  - Because each group sum is converted via `to_string(sum)` and concatenated as characters, sums of `0` become `"0"` and are preserved naturally (as seen in Example 2: `"00000000"` $\rightarrow$ `"000"`).

## 💡 Key Insights

| Concept | Takeaway |
| :--- | :--- |
| **ASCII Digit Conversion** | Subtracting `'0'` (`s[j] - '0'`) converts any digit character `'0'`–`'9'` to its exact integer value `0`–`9` in $O(1)$ time. |
| **Boundary Clamping** | Using `min(i + k, n)` as the inner loop limit cleanly handles partial trailing groups without conditional `if` checks. |
| **Move Semantics (`std::move`)** | `s = move(nextStr)` transfers the internal heap buffer pointer from `nextStr` to `s` in $O(1)$ time, eliminating redundant string copying at the end of every round. |
| **Geometric Length Shrinkage** | Because each block of size $k$ collapses to at most $\lceil \log_{10}(9k + 1) \rceil$ characters, the total work across all rounds sums to $O(n)$. |
