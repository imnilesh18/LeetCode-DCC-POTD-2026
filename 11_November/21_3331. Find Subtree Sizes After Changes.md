## 📝 Problem Statement

You are given a tree rooted at node `0` that consists of `n` nodes numbered from `0` to `n - 1`[cite: 1]. The tree is represented by an array `parent` of size `n`, where `parent[i]` is the parent of node `i`[cite: 1]. Since node `0` is the root, `parent[0] == -1`[cite: 1].

You are also given a string `s` of length `n`, where `s[i]` is the character assigned to node `i`[cite: 1].

We make the following changes on the tree **one time simultaneously** for all nodes `x` from `1` to `n - 1`[cite: 1]:

1. Find the **closest node** `y` to node `x` such that `y` is an **ancestor** of `x`, and `s[x] == s[y]`[cite: 1].
2. If node `y` does not exist, do nothing[cite: 1].
3. Otherwise, **remove** the edge between `x` and its current parent and make node `y` the **new parent** of `x` by adding an edge between them[cite: 1].

Return an array `answer` of size `n` where `answer[i]` is the **size of the subtree rooted at node `i`** in the final tree[cite: 1].

---

## 🔒 Constraints

- `n == parent.length == s.length`[cite: 1]
- `1 <= n <= 10^5`[cite: 1]
- `0 <= parent[i] <= n - 1` for all `i >= 1`[cite: 1]
- `parent[0] == -1`[cite: 1]
- `parent` represents a valid tree[cite: 1].
- `s` consists only of lowercase English letters (`'a'` to `'z'`)[cite: 1].

## 💡 Approach

### 1. Core Intuition & The "Recursion Leap of Faith"
Because a node in this tree can have any number of children (an $n$-ary tree rather than a binary tree), **Depth-First Search (DFS)** is the cleanest and most natural way to traverse and compute subtree properties[cite: 1].

When writing recursive tree algorithms, we rely on the **Recursion Leap of Faith**[cite: 1]:
- Assume that calling `dfs(child)` completely processes the entire subtree rooted at `child`—handling all re-parenting inside that subtree and finalizing `resultSize[child]`[cite: 1].
- Once `dfs(child)` returns to `currNode`, we do not need to manually trace deeper levels; we simply trust that `resultSize[currNode]` already contains the exact count of all nodes that belong in `currNode`'s final subtree[cite: 1].

### 2. Tracking the Closest Matching Ancestor in $O(1)$
To avoid walking up the ancestor chain repeatedly for every node:
1. Build an **adjacency list** `adj` from the `parent` array (`parent[i] -> i` for all `i` from `1` to `n - 1`) so we can traverse top-down from root `0`[cite: 1].
2. Initialize `resultSize` of size `n` with `1` for every node (since every node is always part of its own subtree)[cite: 1].
3. Since `s` contains only lowercase English letters, maintain an array `last` of size `26` (initialized to `-1`), where `last[c]` stores the **most recent ancestor node** on the current DFS recursion path that holds character `'a' + c`[cite: 1].

### 3. Top-Down State Update & Bottom-Up Backtracking
During `dfs(currNode)`:
1. **Query Closest Ancestor**: Extract character index `c = s[currNode] - 'a'` and save `nearestAncestor = last[c]`[cite: 1]. This gives the exact closest ancestor with the same character in $O(1)$ time[cite: 1].
2. **Update Path State for Descendants**: Before recursing into `currNode`'s children, set `last[c] = currNode`[cite: 1]. For any descendant inside `currNode`'s subtree that also has character `c`, `currNode` is now closer than `nearestAncestor`[cite: 1].
3. **Recurse on Children**: Call `dfs(child)` for every `child` in `adj[currNode]`[cite: 1].
4. **Backtrack (`Undo` State Change)**: After returning from all children back to `currNode`, restore `last[c] = nearestAncestor`[cite: 1]. This ensures that sibling subtrees explored later do not mistakenly treat `currNode` as their ancestor[cite: 1].
5. **Re-parent & Accumulate Subtree Size**:
   - If `currNode != 0` (root `0` has no parent), start with `newParent = parent[currNode]`[cite: 1].
   - If `nearestAncestor != -1`, update `newParent = nearestAncestor` and set `parent[currNode] = newParent`[cite: 1].
   - Add `currNode`'s finalized subtree size directly to its new parent: `resultSize[newParent] += resultSize[currNode]`[cite: 1].

### 4. Why Post-Order Accumulation Works Even for Deep Subtrees
Consider a deeper scenario where node `3` (`'a'`, child of `1`, descendant of `0 ('a')`) itself has two children, nodes `6` and `7`[cite: 1]:
- Entering node `3`: `nearestAncestor` is saved as `0`, and `last['a']` is updated to `3`[cite: 1].
- Exploring children `6` and `7`: Both report their subtree sizes (`1` each) back to their parent `3`, updating `resultSize[3]` from `1` to `1 + 1 + 1 = 3`[cite: 1].
- Returning to node `3`: `last['a']` is restored to `0`, `3` re-parents to `0`, and `resultSize[0] += resultSize[3]` adds the entire subtree of size `3` (`1 + 3 = 4`) in one step[cite: 1].

## 💻 Solution Code

### 1. Brute Force Approach (Ancestor Walk + Tree Reconstruction)

```cpp
// Intuition: For each node independently, walk upward through its original ancestors to find the closest matching character, then rebuild the tree and count subtree sizes.
// Approach:
// 1. Copy parent into newParent so all parent updates happen simultaneously without altering ancestor paths mid-query.
// 2. For each node x from 1 to n - 1, climb curr = parent[x] until s[curr] == s[x] or curr == -1, updating newParent[x].
// 3. Build an adjacency list from newParent and run a post-order DFS from node 0 to compute final subtree sizes.
// Time Complexity: O(n^2) in the worst case when the tree is a skewed chain and each node climbs all ancestors to the root.
// Space Complexity: O(n) for the newParent array, adjacency list, answer vector, and recursion stack.

class Solution {
public:
    int countSubtree(int u, vector<vector<int>>& adj, vector<int>& answer) {
        int total = 1; // Count current node itself
        for (int v : adj[u]) {
            total += countSubtree(v, adj, answer); // Accumulate child subtree sizes
        }
        return answer[u] = total;
    }

    vector<int> findSubtreeSizes(vector<int>& parent, string s) {
        int n = parent.size();
        vector<int> newParent = parent; // Store simultaneous changes separately

        // Step 1: Find closest matching ancestor for every node x
        for (int x = 1; x < n; x++) {
            int curr = parent[x];
            while (curr != -1) {
                if (s[curr] == s[x]) {
                    newParent[x] = curr; // Found closest ancestor with same character
                    break;
                }
                curr = parent[curr]; // Move one level up
            }
        }

        // Step 2: Reconstruct the modified tree
        vector<vector<int>> adj(n);
        for (int i = 1; i < n; i++) {
            adj[newParent[i]].push_back(i);
        }

        // Step 3: Compute final subtree sizes via post-order DFS
        vector<int> answer(n, 0);
        countSubtree(0, adj, answer);
        return answer;
    }
};

/*
*
* Dry Run
*
* Input: parent = [-1, 0, 0, 1, 1, 1], s = "abaabc"
*
* Step 1 (Ancestor Walk):
* x = 1 ('b'): parent is 0 ('a') -> no match -> newParent[1] = 0
* x = 2 ('a'): parent is 0 ('a') -> match at 0 -> newParent[2] = 0
* x = 3 ('a'): parent is 1 ('b') -> climb to 0 ('a') -> match at 0 -> newParent[3] = 0
* x = 4 ('b'): parent is 1 ('b') -> match at 1 -> newParent[4] = 1
* x = 5 ('c'): parent is 1 ('b') -> climb to 0 ('a') -> no match -> newParent[5] = 1
* newParent = [-1, 0, 0, 0, 1, 1]
*
* Step 2 & 3 (Tree & Subtree Sizes):
* adj[0] = {1, 2, 3}, adj[1] = {4, 5}
* countSubtree(4) = 1, countSubtree(5) = 1 -> countSubtree(1) = 1 + 1 + 1 = 3
* countSubtree(2) = 1, countSubtree(3) = 1 -> countSubtree(0) = 1 + 3 + 1 + 1 = 6
* Output: [6, 3, 1, 1, 1, 1]
*
*/
```

### 2. Optimized Approach (Single-Pass DFS with Backtracking Ancestor Map)

```cpp
// Intuition: Maintaining the most recent node seen for each of the 26 lowercase letters along the active DFS path lets us find the closest matching ancestor in O(1) time.
// Approach:
// 1. Build a directed adjacency list from parent[i] -> i for all nodes 1 to n - 1.
// 2. Initialize resultSize to 1 for all nodes and last[26] to -1 to track latest character occurrences on the current path.
// 3. Run DFS from root 0: save nearestAncestor = last[c], set last[c] = currNode for descendants, recurse on children, and restore last[c] on backtrack.
// 4. In post-order, attach currNode to nearestAncestor (if valid) and add resultSize[currNode] into resultSize[newParent].
// Time Complexity: O(n) since each node and edge in the tree is visited once during the single DFS traversal.
// Space Complexity: O(n) for storing the adjacency list, resultSize array, and recursion call stack.

//Approach (DFS)
//T.C : O(n)
//S.C : O(n)
class Solution {
public:
    unordered_map<int, vector<int>> adj; // Adjacency list representing parent -> children
    vector<int> resultSize;              // Stores final subtree size for each node
    vector<int> last;                    // Stores latest ancestor index for each char 'a'-'z'

    void dfs(int currNode, string& s, vector<int>& parent) {
        int c = s[currNode] - 'a'; // Map character to 0-25 index

        int nearestAncestor = last[c]; // Closest ancestor with matching character

        last[c] = currNode; // Update latest occurrence for currNode's descendants
        for(int child : adj[currNode]) {
            dfs(child, s, parent); // Recursively solve all child subtrees
        }

        //back to currNode
        last[c] = nearestAncestor; // Backtrack: restore state before leaving currNode

        //if currNode is root, it has no ancestor
        if(currNode != 0) {
            int newParent = parent[currNode]; //old parent

            if(nearestAncestor != -1) {
                newParent = nearestAncestor; // Re-parent to closest matching ancestor
            }

            parent[currNode] = newParent; // Update parent reference

            resultSize[newParent] += resultSize[currNode]; // Add finalized subtree size to new parent
        }
    }

    vector<int> findSubtreeSizes(vector<int>& parent, string s) {
        int n = parent.size();

        //parent[i] = node
        //node is the parent of ith node
        //node ---> i

        for(int i = 1; i < n; i++) {
            int u = parent[i]; //u is the parent
            int v = i;
            adj[u].push_back(v); //u --> v
        }

        resultSize.assign(n, 1); // Every node starts with subtree size 1
        last.assign(26, -1);     // Initially no characters have been seen

        dfs(0, s, parent); // Start single-pass DFS from root 0

        return resultSize;
    }
};

/*
*
* Dry Run
*
* Input: parent = [-1, 0, 0, 1, 1, 1], s = "abaabc"
* Initial: adj = {0: [1, 2], 1: [3, 4, 5]}, resultSize = [1, 1, 1, 1, 1, 1], last = [-1 ... -1]
*
* dfs(0, 'a'): nearestAncestor = -1, last['a'] = 0 -> calls dfs(1), dfs(2)
*   dfs(1, 'b'): nearestAncestor = -1, last['b'] = 1 -> calls dfs(3), dfs(4), dfs(5)
*     dfs(3, 'a'): nearestAncestor = 0, last['a'] = 3 -> no children -> restores last['a'] = 0
*       currNode = 3 != 0 -> nearestAncestor = 0 != -1 -> newParent = 0
*       resultSize[0] += resultSize[3] -> resultSize[0] = 1 + 1 = 2
*     dfs(4, 'b'): nearestAncestor = 1, last['b'] = 4 -> no children -> restores last['b'] = 1
*       currNode = 4 != 0 -> nearestAncestor = 1 != -1 -> newParent = 1
*       resultSize[1] += resultSize[4] -> resultSize[1] = 1 + 1 = 2
*     dfs(5, 'c'): nearestAncestor = -1, last['c'] = 5 -> no children -> restores last['c'] = -1
*       currNode = 5 != 0 -> nearestAncestor = -1 -> newParent = 1 (old parent)
*       resultSize[1] += resultSize[5] -> resultSize[1] = 2 + 1 = 3
*   back to dfs(1): restores last['b'] = -1 -> newParent = 0 -> resultSize[0] += resultSize[1] -> resultSize[0] = 2 + 3 = 5
*   dfs(2, 'a'): nearestAncestor = 0, last['a'] = 2 -> no children -> restores last['a'] = 0
*     currNode = 2 != 0 -> nearestAncestor = 0 -> newParent = 0 -> resultSize[0] += resultSize[2] -> resultSize[0] = 5 + 1 = 6
* back to dfs(0): restores last['a'] = -1 -> currNode == 0 (skipped)
*
* Final resultSize: [6, 3, 1, 1, 1, 1]
*
*/
```

## 📌 Notes

- **Why Simultaneous Updates Work Seamlessly in DFS**: Because the problem specifies that all edge changes occur *simultaneously* based on the **original** ancestor relationships[cite: 1], maintaining `last[26]` strictly along the **original** tree structure during DFS guarantees that every node queries its true closest original ancestor.
- **Root Node Guard (`currNode != 0`)**: Node `0` is the root and has `parent[0] == -1`[cite: 1]. Always guard the parent lookup and `resultSize[newParent]` update with `if (currNode != 0)` to prevent out-of-bounds indexing at `resultSize[-1]`[cite: 1].
- **Adjacency List Optimization**: While `unordered_map<int, vector<int>>` is flexible and clean, using `vector<vector<int>> adj(n)` can further reduce hash overhead in tight competitive programming time limits[cite: 1].

---

## 🔑 Key Insights

1. **Path-State Backtracking Pattern**: Whenever a tree problem asks for the *closest ancestor* satisfying a property from a small fixed domain (like 26 lowercase letters), store the latest occurrence in a fixed-size array before recursing and restore its previous value upon exiting the recursive call[cite: 1].
2. **Post-Order Subtree Aggregation**: By processing `currNode`'s re-parenting *after* visiting all its children, we ensure that any descendants re-parented onto `currNode` have already contributed to `resultSize[currNode]` before `currNode` transfers its total mass to `newParent`[cite: 1].
