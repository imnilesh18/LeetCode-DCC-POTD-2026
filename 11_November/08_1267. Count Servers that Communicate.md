## 📝 Problem Statement

You are given a map of a server center, represented as a `m * n` integer matrix `grid`, where `1` means that on that cell there is a server and `0` means that it is no server. Two servers are said to communicate if they are on the **same row** or on the **same column**.

Return the number of servers that communicate with any other server.

### 🚫 Constraints:
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m <= 250`
- `1 <= n <= 250`
- `grid[i][j] == 0 or 1`

### Understanding the Core Concept
We are given a grid where `1` represents a server and `0` is an empty space. A server can only communicate if there is **at least one other server** in its entire row OR its entire column. If a server is completely isolated (the only `1` in its row and the only `1` in its column), it cannot communicate. We need to find the total count of servers that *can* communicate.

### Approach 1: Brute Force
The most immediate thought is to visit every single cell. Whenever we find a server (`grid[i][j] == 1`), we manually scan its entire row and its entire column. If we spot another server during this scan, we mark our current server as "able to communicate" and increment our count. 
* **Drawback:** We are repeatedly scanning rows and columns for every server, leading to redundant work and a time complexity of $O((m \times n) \times (m + n))$.

### Approach 2: Precomputation (Better)
Instead of scanning rows and columns over and over, we can use extra space to remember the server counts. 
1. **Pre-process:** Create two arrays, `indexRowCount` and `indexColCount`. Iterate through the matrix once, and whenever you see a server at `(row, col)`, increment `indexRowCount[row]` and `indexColCount[col]`.
2. **Evaluate:** Iterate through the matrix a second time. If you find a server, simply check our precomputed arrays: is `indexRowCount[row] > 1` or `indexColCount[col] > 1`? If yes, it communicates!
* **Optimization:** Time complexity drops significantly to $O(m \times n)$.

### Approach 3: Track the "Lone" (Akela) Server (Another Better)
We can optimize the two-pass precomputation method slightly by processing rows intelligently.
1. As we scan each row, we count the servers. We also keep a global tally of servers per column (`colServerCount`).
2. If a row has `> 1` servers, *all* of them can communicate. We immediately add them to our total result. 
3. If a row has exactly `1` server (an "akela" or lone server), it *might* still communicate if its column has other servers. We remember its column index in an array `RowAkelaServerCol`.
4. Finally, we do a quick check over our `RowAkelaServerCol` array. For any lone server we recorded, we check if its corresponding column has `> 1` servers. If so, we increment our result.

## 💻 Solution Code

### 1️⃣ Brute Force Approach

```cpp
// Intuition: For every server found, manually scan its entire row and column to find a communication partner.
// Approach: 
// 1. Traverse every cell in the m x n grid.
// 2. When a server (1) is found, iterate through its row. If another server exists, it can communicate.
// 3. If no server is in the same row, iterate through its column.
// 4. Increment the result if a partner is found in either direction.
// Time Complexity: O((m * n) * (m + n)) - For each of the m*n cells, we potentially scan m + n cells.
// Space Complexity: O(1) - No extra space used besides variables.

class Solution {
public:
    int countServers(vector<vector<int>>& grid) {
        int m = grid.size(), n = grid[0].size();
        int resultServers = 0;

        // Traverse through the grid
        for (int row = 0; row < m; ++row) {
            for (int col = 0; col < n; ++col) {
                if (grid[row][col] == 1) { // Found a server
                    bool canCommunicate = false;

                    // Check for communication in the same row
                    for (int otherCol = 0; otherCol < n; ++otherCol) {
                        if (otherCol != col && grid[row][otherCol] == 1) {
                            canCommunicate = true;
                            break; // Partner found, no need to check further
                        }
                    }

                    // If a server was found in the same row, increment resultServers
                    if (canCommunicate) {
                        resultServers++;
                    } else {
                        // Check for communication in the same column
                        for (int otherRow = 0; otherRow < m; ++otherRow) {
                            if (otherRow != row && grid[otherRow][col] == 1) {
                                canCommunicate = true;
                                break; // Partner found
                            }
                        }

                        // If a server was found in the same column, increment resultServers
                        if (canCommunicate) {
                            resultServers++;
                        }
                    }
                }
            }
        }

        return resultServers;
    }
};

/*
*
* Dry Run
* grid = [[1, 0], [1, 1]]
* m = 2, n = 2
* row 0, col 0: grid[0][0] == 1. Row scan: no partner. Col scan: grid[1][0] == 1. canCommunicate = true. result = 1.
* row 0, col 1: grid[0][1] == 0. Skip.
* row 1, col 0: grid[1][0] == 1. Row scan: grid[1][1] == 1. canCommunicate = true. result = 2.
* row 1, col 1: grid[1][1] == 1. Row scan: grid[1][0] == 1. canCommunicate = true. result = 3.
* Final Result = 3.
*
*/
```

### 2️⃣ Optimized Precomputation Approach

```cpp
// Intuition: Avoid redundant row/col scans by pre-calculating the total number of servers in each row and each column.
// Approach: 
// 1. Create two arrays to store the count of servers for each row and column.
// 2. Do a first pass over the grid to populate these frequency arrays.
// 3. Do a second pass. For any server at (row, col), if the row count > 1 OR col count > 1, it communicates.
// Time Complexity: O(m * n) - We traverse the grid exactly twice.
// Space Complexity: O(m + n) - Used for storing the counts of m rows and n columns.

class Solution {
public:
    int countServers(vector<vector<int>>& grid) {
        int m = grid.size();
        int n = grid[0].size();

        // Arrays to store server counts per row and column
        vector<int> indexColCount(n, 0);
        vector<int> indexRowCount(m, 0);
        
        // Preprocessing: Count servers in each row and column
        for(int row = 0; row < m; row++) {
            for(int col = 0; col < n; col++) {
                if(grid[row][col] == 1) { // found a server at grid[row][col]
                    indexColCount[col] += 1;
                    indexRowCount[row] += 1;
                }
            }
        }

        int resultServers = 0;
        
        // Second pass: Validate if a server can communicate
        for(int row = 0; row < m; row++) {
            for(int col = 0; col < n; col++) {
                // If it's a server AND it's not alone in its row or col
                if(grid[row][col] == 1 && (indexColCount[col] > 1 || indexRowCount[row] > 1)) {
                    resultServers++;
                }
            }
        }
        return resultServers;
    }
};

/*
*
* Dry Run
* grid = [[1, 0], [1, 1]]
* Preprocessing:
* indexRowCount = [1, 2] (Row 0 has 1, Row 1 has 2)
* indexColCount = [2, 1] (Col 0 has 2, Col 1 has 1)
* Second Pass:
* (0, 0): Server exists. indexRowCount[0]=1, indexColCount[0]=2 (>1). Communicates! result = 1.
* (1, 0): Server exists. indexRowCount[1]=2 (>1). Communicates! result = 2.
* (1, 1): Server exists. indexRowCount[1]=2 (>1). Communicates! result = 3.
* Final Result = 3.
*
*/
```

### 3️⃣ Track Lone (Akela) Server Approach

```cpp
// Intuition: Optimize by immediately counting servers in populated rows, leaving only isolated row servers for a secondary column check.
// Approach: 
// 1. Maintain a column frequency array and an array tracking the column index of a lone server per row.
// 2. Iterate through rows. Count servers. If a row has >1 servers, add them all to the result.
// 3. If a row has exactly 1 server, store its column index.
// 4. Finally, check all recorded lone servers. If their column has >1 servers, increment the result.
// Time Complexity: O(m * n) - One full matrix traversal and one small array traversal.
// Space Complexity: O(m + n) - Used for tracking column counts and lone server locations.

class Solution {
public:
    int countServers(vector<vector<int>>& grid) {
        int m = grid.size();
        int n = grid[0].size();

        vector<int> colServerCount(n, 0); // Stores total servers in each column
        vector<int> RowAkelaServerCol(m, -1); // Stores col index if a row has exactly 1 server

        int resultServers = 0;

        for(int row = 0; row < m; row++) {
            int countServersRow = 0;
            for(int col = 0; col < n; col++) {
                if(grid[row][col] == 1) {
                    countServersRow += 1;
                    colServerCount[col]++;
                    RowAkelaServerCol[row] = col; // Temporarily mark as the lone server's col
                }
            }

            // If row has multiple servers, they all communicate
            if(countServersRow > 1) {
                resultServers += countServersRow;
                RowAkelaServerCol[row] = -1; // Overwrite because there is no akela (lone) server in this row
            }
        }

        // Check Akela (lone) servers in each row against their column counts
        for(int row = 0; row < m; row++) {
            if(RowAkelaServerCol[row] != -1) { // Found a lone server in this row
                int col = RowAkelaServerCol[row];
                if(colServerCount[col] > 1) { // Does its column save it?
                    resultServers += 1;
                }
            }
        }

        return resultServers;
    }
};

/*
*
* Dry Run
* grid = [[1, 0], [0, 1], [1, 1]]
* First Pass:
* Row 0: count = 1. colServerCount[0] = 1. RowAkelaServerCol[0] = 0.
* Row 1: count = 1. colServerCount[1] = 1. RowAkelaServerCol[1] = 1.
* Row 2: count = 2. colServerCount[0] = 2, colServerCount[1] = 2. RowAkelaServerCol[2] = -1. result = 2.
* Second Pass (Akela Check):
* Row 0: Lone server at col 0. colServerCount[0] is 2 (>1). result = 2 + 1 = 3.
* Row 1: Lone server at col 1. colServerCount[1] is 2 (>1). result = 3 + 1 = 4.
* Final Result = 4.
*
*/
```
