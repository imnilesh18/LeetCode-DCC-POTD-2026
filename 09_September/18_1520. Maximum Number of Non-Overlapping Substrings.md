# 1520. Maximum Number of Non-Overlapping Substrings

**Problem Link:** [Maximum Number of Non-Overlapping Substrings](https://leetcode.com/problems/maximum-number-of-non-overlapping-substrings/)  
**Problem Name:** Maximum Number of Non-Overlapping Substrings  
**Difficulty:** 🔴 Hard  
**Tags:** `Hash Table`, `String`, `Greedy`, `Sorting`  

---

## 📝 Problem Statement

Given a string `s` of lowercase letters, you need to find the maximum number of non-empty substrings of `s` that meet the following conditions:

1. The substrings do not overlap, that is for any two substrings `s[i..j]` and `s[x..y]`, either `j < x` or `i > y` is true.
2. A substring that contains a certain character `c` must also contain **all occurrences** of `c`.

Find the maximum number of substrings that meet the above conditions. If there are multiple solutions with the same number of substrings, return the one with the **minimum total length**. It can be shown that there exists a unique solution of minimum total length.

*Notice that you can return the substrings in any order.*

---

## 💡 Examples

### Example 1
| Input | Output |
| :--- | :--- |
| `s = "adefaddaccc"` | `["e","f","ccc"]` |

<details>
<summary><b>Explanation</b></summary>
The following are all the possible substrings that meet the conditions:
<br>
<code>["adefaddaccc", "adefadda", "ef", "e", "f", "ccc"]</code>
<br>
If we choose the first string, we cannot choose anything else and we'd get only 1. If we choose "adefadda", we are left with "ccc" which is the only one that doesn't overlap, thus obtaining 2 substrings. Notice also, that it's not optimal to choose "ef" since it can be split into two. Therefore, the optimal way is to choose <code>["e","f","ccc"]</code> which gives us 3 substrings. No other solution of the same number of substrings exist.
</details>

### Example 2
| Input | Output |
| :--- | :--- |
| `s = "abbaccd"` | `["d","bb","cc"]` |

<details>
<summary><b>Explanation</b></summary>
Notice that while the set of substrings <code>["d","abba","cc"]</code> also has length 3, it's considered incorrect since it has a larger total length.
</details>

## ⚠️ Constraints

- `1 <= s.length <= 10^5`
- `s` contains only lowercase English letters.

---

## 🧠 Key Insights

1. **Start and End Boundaries:** Every valid substring centered around a character must at least stretch from the very first occurrence to the very last occurrence of that character.
2. **Expanding Boundaries:** If there are other characters sandwiched between the first and last occurrence of our chosen character, we MUST include their full occurrences as well, which might push the `end` boundary further to the right.
3. **Invalid Starting Points:** If we find an inner character whose first occurrence is strictly *before* our chosen character's starting position, our chosen character is an invalid starting point. We cannot form a valid substring starting exactly there without expanding to the left.
4. **Greedy Traversal (Right-to-Left):** By processing the string from right to left, we encounter the starting positions of smaller, nested valid substrings *before* the starting positions of larger, enclosing substrings. Greedily picking these smaller valid substrings ensures we get the maximum number of substrings with the minimum total length.

---

## 🛠 Approach

1. **Calculate Global Bounds:** Iterate through the string to populate two arrays of size 26, `start` and `end`, which store the first and last index occurrences of every character.
2. **Validate and Extend Bounds:** 
   - Iterate through each character `c` present in the string.
   - Sweep from `start[c]` to `end[c]`. If any character within this range has a starting index less than `start[c]`, mark character `c` as an invalid starting point (because it requires leftward expansion).
   - Otherwise, update `end[c]` to be the maximum of the current `end[c]` and the ending index of the inner characters.
3. **Greedy Extraction:** 
   - Loop through the string from right to left (index `n-1` down to `0`).
   - If the current index matches the `start` index of a valid character, and its extended `end` is strictly less than the starting index of the last taken substring (to guarantee non-overlapping), slice the substring and add it to the result.
   - Update the `lastTakenStart` to the current index.

## 💻 Solution Code

### Optimized Solution (C++)

```cpp
// Intuition:
// To find the maximum number of non-overlapping substrings with minimum length, we need to find the valid boundaries for each character. A valid substring starting at a character must include all occurrences of every character within its range. We can greedily pick the shortest valid substrings by processing from right to left.

// Approach:
// 1. Find the first (start) and last (end) occurrence of each character.
// 2. For each character, try to expand its `end` boundary by checking all characters within its range. If we find a character that starts before our current character's `start`, this current character cannot be a valid starting point (mark isValid = false).
// 3. Iterate through the string from right to left. When a valid starting point is found, and its expanded `end` doesn't overlap with the previously taken substring, add it to the result.

// Time Complexity: O(N) where N is the length of the string. The O(26 * N) nested loop behaves linearly overall.
// Space Complexity: O(1) space auxiliary space (or O(26)), as we use fixed-size arrays for English alphabet characters.

class Solution {
public:
    vector<string> maxNumOfSubstrings(string s) {
        int n = s.length();

        // Track start, end, and validity of each character
        vector<int> start(26, -1);
        vector<int> end(26, 0);
        vector<bool> isValid(26, true);

        vector<string> result;

        // Step 1: Find first and last occurrences of each character
        for(int i = 0; i < n; i++) {
            int idx = s[i] - 'a';

            if(start[idx] == -1) {
                start[idx] = i; // First occurrence
            }
            end[idx] = i; // Last occurrence (gets continuously updated)
        }

        // Step 2: Extend the end boundary and check validity
        for(int c = 0; c < 26; c++) { // checking all characters
            if(start[c] == -1) continue; // Character not present
            
            // Check all characters within the current bounds of character 'c'
            for(int i = start[c]; i <= end[c]; i++) {
                // If an inner character starts before 'c', 'c' is an invalid starting point
                if(start[s[i]-'a'] < start[c]) {
                    isValid[c] = false;
                    break;
                }
                
                // Expand the end boundary if an inner character goes further right
                end[c] = max(end[c], end[s[i]-'a']);
            }
        }

        int lastTakenStart = INT_MAX; // Track overlap boundary

        // Step 3: Greedily pick valid substrings from right to left
        for(int i = n-1; i >= 0; i--) {
            int c = s[i] - 'a';

            if(!isValid[c]) continue; // Skip if it's an invalid starting point

            // If we are exactly at the start of a valid char & it doesn't overlap with the last taken string
            if(i == start[c] && end[c] < lastTakenStart) {
                result.push_back(s.substr(i, end[c] - i + 1));
                lastTakenStart = i; // Update overlap boundary
            }
        }
        return result;
    }
};

/*
*
* Dry Run
*
* Input: s = "adefaddaccc"
*
* 1. Calculate boundaries:
*    'a': start=0, end=7
*    'c': start=8, end=10
*    'd': start=1, end=6
*    'e': start=2, end=2
*    'f': start=3, end=3
*
* 2. Validate and Extend:
*    'a': within [0,7] are 'd','e','f'. max end becomes 7. Valid.
*    'd': within [1,6] is 'e','f','a'. But start['a'](0) < start['d'](1). Invalid!
*    'e': within [2,2] is 'e'. Valid.
*    'f': within [3,3] is 'f'. Valid.
*    'c': within [8,10] is 'c'. Valid.
*
* 3. Greedy Traversal (Right to Left):
*    - i=10 to 8: 'c'. At i=8 (start of 'c'), end=10 < INT_MAX. Pick "ccc". lastTakenStart = 8.
*    - i=7 to 4: skip (not starting points of valid segments).
*    - i=3: 'f'. At i=3 (start of 'f'), end=3 < 8. Pick "f". lastTakenStart = 3.
*    - i=2: 'e'. At i=2 (start of 'e'), end=2 < 3. Pick "e". lastTakenStart = 2.
*    - i=0: 'a'. At i=0 (start of 'a'), end=7. Since 7 is NOT < 2, it overlaps! Skip.
*
* 4. Result: ["ccc", "f", "e"]
*
*/

```

## 📌 Notes

* Iterating from **right-to-left** acts as a greedy safeguard, naturally uncovering nested (shorter) substrings before encompassing (larger) ones.
* Tracking the `lastTakenStart` effortlessly prevents any overlap intersections since the parsing evaluates the substrings rigorously from the right-hand side backward.
