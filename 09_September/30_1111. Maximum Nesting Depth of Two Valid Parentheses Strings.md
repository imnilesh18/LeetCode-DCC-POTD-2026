## 📖 Problem Statement

A string is a valid parentheses string (denoted **VPS**) if and only if it consists of `"("` and `")"` characters only, and:

1. It is the empty string, or
2. It can be written as `AB` (`A` concatenated with `B`), where `A` and `B` are VPS's, or
3. It can be written as `(A)`, where `A` is a VPS.

We can similarly define the nesting depth `depth(S)` of any VPS `S` as follows:
* `depth("") = 0`
* `depth(A + B) = max(depth(A), depth(B))`, where `A` and `B` are VPS's
* `depth("(" + A + ")") = 1 + depth(A)`, where `A` is a VPS.

For example, `""`, `"()()"`, and `"()(()())"` are VPS's (with nesting depths 0, 1, and 2), and `")("` and `"(()"` are not VPS's.

Given a VPS `seq`, split it into two disjoint subsequences `A` and `B`, such that `A` and `B` are VPS's (and `A.length + B.length = seq.length`). The subsequences may not necessarily be contiguous.

Now choose any such `A` and `B` such that `max(depth(A), depth(B))` is the **minimum possible value**.

Return an answer array (of length `seq.length`) that encodes such a choice of `A` and `B`: `answer[i] = 0` if `seq[i]` is part of `A`, else `answer[i] = 1`. Note that even though multiple answers may exist, you may return any of them.

## 🧠 Approach & Key Insights

To minimize the maximum depth of the two new valid parentheses strings (`A` and `B`), the most optimal strategy is to distribute the original depth as evenly as possible between them. 

If the total maximum depth of the original string is `D`, the best we can achieve for `A` and `B` is `D / 2`. 

### The Core Logic:
1. **Track Current Depth:** As we iterate through the sequence, we maintain a `depth` counter. It increases when we encounter an open bracket `(` and decreases when we encounter a close bracket `)`.
2. **Evenly Distribute:** To split the depth cleanly in half, we can rely on the parity (odd/even status) of the current depth. 
   - We assign brackets appearing at an **odd depth** to Group 1 (or `B`).
   - We assign brackets appearing at an **even depth** to Group 0 (or `A`).
3. **Handling Closing Brackets:** A closing bracket `)` inherently closes the *current* depth level before dropping down to the previous level. Therefore, we assign the closing bracket based on the current depth *first*, and only decrease the depth counter *afterward*.

Imagine the sequence `(()())`.
* The first `(` has a depth of 1 (Odd -> Group 1).
* The next `(` increases depth to 2 (Even -> Group 0).
* The next `)` belongs to the current depth 2 (Even -> Group 0), then depth drops to 1.
* The next `(` pushes depth back to 2 (Even -> Group 0).
* The next `)` belongs to depth 2 (Even -> Group 0), depth drops to 1.
* The final `)` belongs to depth 1 (Odd -> Group 1).

By alternating based on depth parity, neither group ever accumulates more than half the total nesting!

## 💻 Solution Code (Optimal)

```cpp
// Intuition: To minimize the maximum depth, we should evenly distribute the nesting between the two subsequences. By routing brackets at odd depths to one group and even depths to the other, we naturally halve the overall maximum depth.
// Approach: Iterate through the string maintaining a depth counter. For '(', increment depth and assign based on parity (odd=1, even=0). For ')', assign based on the current depth's parity first, then decrement the depth to properly close it.
// Time Complexity: O(N) where N is the length of the string, as we only perform a single pass over the sequence.
// Space Complexity: O(1) auxiliary space, because we only use a few integer variables (excluding the space required for the output array itself).

class Solution {
public:
    vector<int> maxDepthAfterSplit(string seq) {
        vector<int> result(seq.size());
        int d = 0; // Tracks the current nesting depth

        for (int i = 0; i < seq.size(); i++) {
            if (seq[i] == '(') {
                d++; // Entering a new nested level
                // Assign to group 0 if even depth, group 1 if odd depth
                result[i] = d % 2 == 0 ? 0 : 1;
            } 
            else {
                // Closing the current level, so evaluate parity before decrementing
                result[i] = d % 2 == 0 ? 0 : 1;
                d--; // Exiting the nested level
            }
        }

        return result;
    }
};

/*
*
* Dry Run
*
* Input: seq = "(()())"
* Initial state: result = [0, 0, 0, 0, 0, 0], d = 0
*
* i = 0 | seq[0] = '(' | d becomes 1. Parity (1 % 2) is 1. result[0] = 1.
* i = 1 | seq[1] = '(' | d becomes 2. Parity (2 % 2) is 0. result[1] = 0.
* i = 2 | seq[2] = ')' | Parity of d(2) is 0. result[2] = 0. Then d becomes 1.
* i = 3 | seq[3] = '(' | d becomes 2. Parity (2 % 2) is 0. result[3] = 0.
* i = 4 | seq[4] = ')' | Parity of d(2) is 0. result[4] = 0. Then d becomes 1.
* i = 5 | seq[5] = ')' | Parity of d(1) is 1. result[5] = 1. Then d becomes 0.
*
* Output: [1, 0, 0, 0, 0, 1] 
* (Note: This is a perfectly valid split where max depth is minimized).
*
*/
```
