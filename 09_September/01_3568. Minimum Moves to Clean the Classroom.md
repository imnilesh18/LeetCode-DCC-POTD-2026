## 📝 Problem Statement

You are given an `m x n` grid `classroom` where a student volunteer is tasked with cleaning up litter scattered around the room. Each cell in the grid is one of the following:

*   `'S'`: Starting position of the student (exactly one in the grid).
*   `'L'`: Litter that must be collected (once collected, the cell becomes empty).
*   `'R'`: Reset area that restores the student's energy to full capacity, regardless of their current energy level (can be used multiple times).
*   `'X'`: Obstacle the student cannot pass through.
*   `'.'`: Empty space.

You are also given an integer `energy`, representing the student's maximum energy capacity. The student starts with this `energy` from the starting position `'S'`.

Each move to an adjacent cell (up, down, left, or right) costs `1` unit of energy. If the energy reaches `0`, the student can only continue if they are on a reset area `'R'`, which resets the energy to its maximum capacity `energy`.

Return the **minimum number of moves** required to collect all litter items, or `-1` if it's impossible.

---

## 🚦 Constraints

*   `1 <= m == classroom.length <= 20`
*   `1 <= n == classroom[i].length <= 20`
*   `classroom[i][j]` is one of `'S'`, `'L'`, `'R'`, `'X'`, or `'.'`.
*   `1 <= energy <= 50`
*   There is exactly one `'S'` in the grid.
*   There are at most `10` `'L'` cells in the grid.

## 🚀 Approach

Finding the "minimum number of moves" in an unweighted grid is a classic Breadth-First Search (BFS) problem. However, applying a standard BFS (where we only track the visited `row` and `col`) will **fail** here. 

### Why Standard BFS Fails:
In a standard BFS, once we visit a cell `(r, c)`, we mark it as `visited` so we never return. But in this classroom, a student might need to revisit a cell for multiple reasons:
1. They might arrive with **more energy** this time (e.g., they took a detour to a Reset 'R' cell).
2. They might arrive having collected a **different set of litters**. 

### The Solution: 4D State Representation
To uniquely identify a scenario and avoid infinite loops while allowing necessary backtracking, our BFS state must encompass four variables:
1. `row`: Current row.
2. `col`: Current column.
3. `energy`: Remaining energy.
4. `collected_mask`: A bitmask representing exactly *which* litters have been collected.

**Using Bitmasks:**
Since the constraints guarantee a maximum of 10 litters (`L <= 10`), we can represent the collection status of all litters using a 10-bit integer. 
* We assign a unique ID (from `0` to `k-1`) to each 'L' cell.
* A bitmask `00101` in binary (value 5) would mean the 0th and 2nd litters have been collected.
* Our goal is reached when the bitmask equals `(1 << k) - 1` (i.e., all `k` bits are set to 1).

We push this 4D state into our BFS queue and traverse level by level, updating the bitmask whenever we step on a new 'L' and restoring energy whenever we step on an 'R'.

## 💻 Solution Code (Optimized BFS)

```cpp
// Intuition: 
// A standard 2D BFS fails because returning to a previously visited cell might be optimal 
// if we have more energy or have collected different litters. Therefore, we must treat 
// (row, col, energyLeft, collectedMask) as a unique state to guarantee finding the shortest path.
//
// Approach: 
// 1. Traverse the grid to locate the start 'S' and assign a unique bit ID (0 to k-1) to every 'L'.
// 2. Initialize a 4D visited array `seen[m][n][energy+1][2^k]`.
// 3. Push the initial state (startRow, startCol, maxEnergy, 0) into a queue.
// 4. Perform level-order BFS. For each move, deduct 1 energy. 
// 5. If we step on 'R', restore energy to max. If we step on 'L', update the mask using Bitwise OR.
// 6. Return the move count the moment `collectedMask` equals `(1 << k) - 1`.
//
// Time Complexity: O(m * n * E * 2^k), where m x n is the grid size, E is max energy, and k is the total number of litters. We visit each unique state at most once.
// Space Complexity: O(m * n * E * 2^k) to store the 4D `seen` vector and the BFS queue.

class Solution {
public:
    // Typedefs to make the 4D vector declaration clean and readable
    using VB = vector<bool>;
    using VVB = vector<VB>;
    using VVVB = vector<VVB>;
    using VVVVB = vector<VVVB>;
    
    // Direction vectors for moving Right, Left, Up, Down
    vector<vector<int>> directions = {{0, 1}, {0, -1}, {-1, 0}, {1, 0}};
    
    // Structure to hold our unique BFS 4D state
    struct State {
            int row;
            int col;
            int energyLeft;
            int collectedMask;
    };

    int minMoves(vector<string>& classroom, int energy) {
        int m = classroom.size();
        int n = classroom[0].size();
        int maxEnergy = energy;

        // Stores the bit position (0 to k-1) for each specific litter
        int litterBit[20][20]; 
        int litterCount = 0;
        int startRow = 0;
        int startCol = 0;
        
        // Step 1: Pre-process the grid to find 'S' and label 'L's
        for (int r = 0; r < m; ++r) {
            for (int c = 0; c < n; ++c) {
                litterBit[r][c] = -1; // Default state
                if (classroom[r][c] == 'S') {
                    startRow = r;
                    startCol = c;
                } else if (classroom[r][c] == 'L') {
                    litterBit[r][c] = litterCount;
                    litterCount++;
                }
            }
        }

        // Target mask where all 'litterCount' bits are set to 1
        int allCollected = (1 << litterCount) - 1;
        
        // Edge case: No litter to collect
        if (litterCount == 0) 
            return 0;

        // Step 2: Initialize 4D Visited array
        VVVVB seen(m, VVVB(n, VVB(maxEnergy + 1, VB(1 << litterCount, false))));

        // Step 3: Initialize BFS Queue
        queue<State> que;
        que.push({startRow, startCol, maxEnergy, 0});
        seen[startRow][startCol][maxEnergy][0] = true;

        int moves = 0;

        // Step 4: Level-order BFS traversal
        while (!que.empty()) {
            int currSize = que.size();

            // Process all states at the current BFS depth (1 move)
            while (currSize--) {
                State current = que.front();
                que.pop();

                // Goal check: All litters collected
                if (current.collectedMask == allCollected) 
                    return moves;
                    
                // If out of energy at this cell, we cannot move further from here
                if (current.energyLeft == 0) 
                    continue;

                // Explore all 4 possible directions
                for (auto& dir : directions) {
                    int nextRow = current.row + dir[0];
                    int nextCol = current.col + dir[1];

                    // Boundary check
                    if (nextRow < 0 || nextRow >= m || nextCol < 0 || nextCol >= n) 
                        continue;

                    char cell = classroom[nextRow][nextCol];
                    
                    // Obstacle check
                    if (cell == 'X') 
                        continue;

                    // Compute resulting energy and mask for the next cell
                    int nextEnergy = current.energyLeft - 1;
                    int nextMask   = current.collectedMask;

                    // Handle special cells
                    if (cell == 'R') {
                        nextEnergy = maxEnergy; // Restore energy
                    } else if (cell == 'L') {
                        // Mark this specific litter's bit as collected
                        nextMask |= (1 << litterBit[nextRow][nextCol]);
                    }

                    // Step 5: If this exact 4D state hasn't been visited, push to queue
                    if (!seen[nextRow][nextCol][nextEnergy][nextMask]) {
                        seen[nextRow][nextCol][nextEnergy][nextMask] = true;
                        que.push({nextRow, nextCol, nextEnergy, nextMask});
                    }
                }
            }
            // Increment move counter after completing one full level expansion
            moves++;
        }

        // Impossible to collect all litter
        return -1;
    }
};

/*
*
* Dry Run
* Grid: ["S.", "XL"], maxEnergy: 2
* 
* Setup: 
* - Start at (0,0) -> 'S'
* - Litter at (1,1) -> assigned bit 0. allCollected = 1 (binary 01)
* 
* BFS Level 0: 
* Queue: [{row: 0, col: 0, energy: 2, mask: 0}]
* moves = 0
* 
* BFS Level 1:
* Pop {0, 0, 2, 0}.
* Explore dir (0, 1) -> (0, 1) valid. Cell is '.'. 
*   nextEnergy = 2 - 1 = 1. nextMask = 0.
*   Push {0, 1, 1, 0}
* Explore dir (1, 0) -> (1, 0) is 'X'. Skip.
* moves = 1
* 
* BFS Level 2:
* Pop {0, 1, 1, 0}.
* Explore dir (1, 1) -> (1, 1) valid. Cell is 'L'.
*   nextEnergy = 1 - 1 = 0.
*   nextMask = 0 | (1 << 0) = 1.
*   Push {1, 1, 0, 1}
* moves = 2
*
* BFS Level 3:
* Pop {1, 1, 0, 1}.
* current.collectedMask (1) == allCollected (1). Goal Reached!
* Return moves (2).
*
*/
```

## 🔑 Key Insights

1. **State Space Definition:** In pathfinding problems, defining what constitutes a "visited" node is half the battle. Whenever you can revisit coordinates under different conditions (like picking up keys, having varying fuel/energy, or carrying items), those conditions must be appended to the visited state.
2. **Bitmasking for Collections:** Whenever a problem asks to track a set of collected items and the maximum number of items is very small (usually `<= 15`), bitmasking is the optimal way to represent the set as a single integer, allowing rapid $O(1)$ state lookups.
