## 📝 Problem Statement

Given a string `s`, return the number of distinct non-empty subsequences of `s`. Since the answer may be very large, return it modulo `10^9 + 7`.

A subsequence of a string is a new string that is formed from the original string by deleting some (can be none) of the characters without disturbing the relative positions of the remaining characters. (i.e., `"ace"` is a subsequence of `"abcde"` while `"aec"` is not).

---

## 🚦 Constraints

- `1 <= s.length <= 2000`
- `s` consists of lowercase English letters.

---

## 💡 Examples

| Input | Output | Explanation |
| :--- | :--- | :--- |
| `s = "abc"` | `7` | The 7 distinct subsequences are `"a"`, `"b"`, `"c"`, `"ab"`, `"ac"`, `"bc"`, and `"abc"`. |
| `s = "aba"` | `6` | The 6 distinct subsequences are `"a"`, `"b"`, `"ab"`, `"aa"`, `"ba"`, and `"aba"`. |
| `s = "aaa"` | `3` | The 3 distinct subsequences are `"a"`, `"aa"` and `"aaa"`. |

## 🧠 Approach & Explanation

The problem asks for the count of **unique, non-empty subsequences** of a given string.

### 1. Brute Force (Generates Memory Limit Exceeded)
The most basic approach is to use standard recursion to generate all possible subsequences. At every character, we have two choices:
1. Pick the current character.
2. Do not pick the current character.

By storing these sequences in an `unordered_set`, we can naturally filter out the duplicates. However, this generates $2^n$ subsequences. For $n = 2000$, $2^{2000}$ is astronomically large and will easily result in a **Memory Limit Exceeded (MLE)** and **Time Limit Exceeded (TLE)**.

### 2. Optimized DP Approach (Thinking from Scratch)
Let's analyze how subsequences are formed dynamically:
- Let the string be `s = "abc"`. 
- Initially, we have exactly $1$ subsequence: the empty string `""`.
- When `'a'` arrives: We can either append `'a'` to the existing subsequences or not. 
  - Not appending gives: `""`
  - Appending gives: `"a"`
  - Total subsequences = $2$ (which is $2 \times 1$).
- When `'b'` arrives: We double the previous subsets.
  - Previous: `""`, `"a"`
  - Appending `'b'`: `"b"`, `"ab"`
  - Total subsequences = $4$.
- When `'c'` arrives: Again, double the previous subsets.
  - Total subsequences = $8$.

**General Formula**: `Count(n) = 2 * Count(n-1)`

### 3. Handling Duplicates
What happens if the string is `"aba"`?
- Initially: `""` (Count = 1)
- After `'a'`: `""`, `"a"` (Count = 2)
- After `'b'`: `""`, `"a"`, `"b"`, `"ab"` (Count = 4)
- After the second `'a'`: By standard doubling, we would get $8$ subsequences. However, appending `'a'` to `""` gives `"a"`, which we already generated when the *first* `'a'` appeared! 

**The Rule to Remove Duplicates**: 
When a character repeats, the duplicate subsequences are exactly the ones formed by appending this character to the sequences that existed *just before* the character's previous occurrence.
Thus:
`Duplicates = Count(just before the previous occurrence of the current character)`

We can maintain an array `lastSeen` (size 26) to store the 1-based index where a character was last encountered. Whenever we process a character, we check `lastSeen`. If it's greater than 0, we subtract the subsequences formed up to `lastSeen - 1`.

### 4. Final Adjustment
The problem requires **non-empty** subsequences. Since our calculations naturally include the empty string `""` from the very beginning, we simply subtract $1$ from our final result.

## 💻 Solution Code

### Brute Force Approach (MLE)

```cpp
// Intuition: Generate all possible subsequences by exploring both pick and not-pick decisions for every character.
// Approach: Recursively traverse the string. At each index, make two branches. Store results in a hash set to keep only unique non-empty subsequences.
// Time Complexity: O(2^n) because every character has 2 independent choices (pick or skip).
// Space Complexity: O(2^n) to store all the generated subsets in the recursive call stack and unordered set.
class Solution {
public:
    int n;
    unordered_set<string> st;
    int dp[2001];

    void solve(int i, string temp, string &s) {
        // Base case: Reached the end of the string
        if(i == n){
            if(temp.size()) // Ignore empty strings
                st.insert(temp);
            return;
        }

        // Choice 1: Include the current character
        solve(i+1, temp+s[i], s);
        
        // Choice 2: Exclude the current character
        solve(i+1, temp, s);
    }

    int distinctSubseqII(string s) {
        n = s.size();
        solve(0, "", s);
        return st.size(); // Set size gives the count of unique subsequences
    }
};

/*
*
* Dry Run
* string: "aba"
* solve(0, "")
*  -> pick 'a': solve(1, "a")
*      -> pick 'b': solve(2, "ab")
*          -> pick 'a': solve(3, "aba") -> inserts "aba"
*          -> skip 'a': solve(3, "ab")  -> inserts "ab"
*      -> skip 'b': solve(2, "a")
*          -> pick 'a': solve(3, "aa")  -> inserts "aa"
*          -> skip 'a': solve(3, "a")   -> inserts "a"
*  -> skip 'a': solve(1, "")
*      -> pick 'b': solve(2, "b")
*          -> pick 'a': solve(3, "ba")  -> inserts "ba"
*          -> skip 'a': solve(3, "b")   -> inserts "b"
*      -> skip 'b': solve(2, "")
*          -> pick 'a': solve(3, "a")   -> "a" is already in set (duplicate skipped)
*          -> skip 'a': solve(3, "")    -> empty string ignored
* Final Set: {"aba", "ab", "aa", "a", "ba", "b"} -> size is 6
*
*/
```

### Recursion + Memoization (Top-Down DP)

```cpp
// Intuition: Avoid generating string subsets. Instead, mathematically count subsequences by doubling previous results and subtracting duplicate structures.
// Approach: Recursively fetch count from n-1, multiply by 2. If the current character appeared before, subtract the subsequences generated just before its last appearance. Memoize states.
// Time Complexity: O(n) because each of the 'n' states is calculated exactly once due to memoization.
// Space Complexity: O(n) for the recursion stack, the 'dp' array, and the 'prev' array tracking previous occurrences.
class Solution {
public:
    int M = 1e9+7;
    int dp[2001];
    vector<int> prev; // prev[n] = last time when we saw this nth character (1-based indexing)

    int solve(int n) {
        // Base case: 0 characters means exactly 1 subsequence (the empty string)
        if(n == 0)
            return 1;

        // Return memoized result if available
        if(dp[n] != -1)
            return dp[n];
        
        // Double the subsets generated by the previous n-1 characters
        int total = (2 * solve(n-1)) % M;

        // If the current character was seen before, remove duplicates
        if(prev[n] != 0) {
            int duplicates = solve(prev[n] - 1); // Count just before the previous occurrence
            total = (total - duplicates + M) % M; // Add M to avoid negative modulo values
        }

        return dp[n] = total; // Store and return state
    }

    int distinctSubseqII(string s) {
        int n = s.length();

        memset(dp, -1, sizeof(dp));
        prev.assign(n+1, 0);

        vector<int> lastSeen(26, 0); // Tracks 1-based index of last appearance
        
        // Populate the 'prev' array using the lastSeen tracker
        for(int i = 1; i <= n; i++) {
            int idx = s[i-1] - 'a';
            prev[i] = lastSeen[idx];
            lastSeen[idx] = i; // Update last seen index
        }

        // Subtract 1 at the end to exclude the empty subsequence
        return (solve(n) - 1 + M) % M;
    }
};

/*
*
* Dry Run
* string: "aba" (n = 3)
* 
* lastSeen Setup (1-based):
* i=1 ('a'): prev[1] = 0, lastSeen['a'] = 1
* i=2 ('b'): prev[2] = 0, lastSeen['b'] = 2
* i=3 ('a'): prev[3] = 1, lastSeen['a'] = 3
* 
* solve(3):
*  requires solve(2) -> solve(1) -> solve(0)
*  solve(0) returns 1 (base case)
*  solve(1): total = 2*solve(0) = 2. prev[1]=0. Returns 2. (dp[1]=2)
*  solve(2): total = 2*solve(1) = 4. prev[2]=0. Returns 4. (dp[2]=4)
*  solve(3): total = 2*solve(2) = 8. prev[3]=1 (duplicate exists!)
*    -> duplicates = solve(prev[3]-1) = solve(0) = 1.
*    -> total = (8 - 1) % M = 7. Returns 7. (dp[3]=7)
*
* Final Answer: (solve(3) - 1) = 7 - 1 = 6.
*
*/
```

### Bottom-Up Dynamic Programming (Optimized Iterative)

```cpp
// Intuition: We can iteratively calculate the subset counts from 1 to n, eliminating the overhead of the recursive call stack.
// Approach: Build a 1D DP table where dp[i] is the number of distinct subsequences up to index i. Double the previous count and conditionally subtract duplicates using a 'prev' mapping array.
// Time Complexity: O(n) as we only loop through the string length n exactly once.
// Space Complexity: O(n) to store the 'dp' array and 'prev' mapping array.
class Solution {
public:
    int M = 1e9+7;
    int dp[2001];
    vector<int> prev; // prev[n] = last time when we saw this nth character (1-based indexing)

    int distinctSubseqII(string s) {
        int n = s.length();

        memset(dp, -1, sizeof(dp));
        prev.assign(n+1, 0);

        vector<int> lastSeen(26, 0); // To track occurrences of characters
        
        // Build the prev index tracking array
        for(int i = 1; i <= n; i++) {
            int idx = s[i-1] - 'a';
            prev[i] = lastSeen[idx];
            lastSeen[idx] = i; // Update to latest 1-based index
        }

        dp[0] = 1; // Base case: if(n == 0) return 1 (empty subsequence)

        // Iteratively calculate the number of subsequences up to character i
        for(int i = 1; i <= n; i++) {
            int total = (2 * dp[i-1]) % M; // Double the previous count

            // Check if the current character has appeared before
            if(prev[i] != 0) {
                int duplicates = dp[prev[i] - 1]; // Deduct subsets before last occurrence
                total = (total - duplicates + M) % M; // Safe modulo subtraction
            }

            dp[i] = total; // Store result for current prefix
        }

        // Discard the empty string sequence
        return (dp[n] - 1 + M) % M;
    }
};

/*
*
* Dry Run
* string: "aba" (n=3)
* Initialization: dp[0] = 1, prev = [0, 0, 0, 1]
* 
* Loop i = 1 (char 'a'):
*  total = (2 * dp[0]) = 2
*  prev[1] == 0, so no duplicates subtracted.
*  dp[1] = 2
* 
* Loop i = 2 (char 'b'):
*  total = (2 * dp[1]) = 4
*  prev[2] == 0, so no duplicates subtracted.
*  dp[2] = 4
* 
* Loop i = 3 (char 'a'):
*  total = (2 * dp[2]) = 8
*  prev[3] == 1, duplicate found!
*  duplicates = dp[prev[3] - 1] = dp[0] = 1
*  total = 8 - 1 = 7
*  dp[3] = 7
* 
* Final result = dp[n] - 1 = dp[3] - 1 = 7 - 1 = 6
*
*/
```

## 📌 Notes & Key Insights
- Always remember that the baseline growth formula for subsets is `f(n) = 2 * f(n-1)`. 
- By observing pattern overlaps mathematically, we switch from generating sequences ($O(2^n)$) to predicting their quantities ($O(n)$).
- When doing modular arithmetic containing subtractions (like `total - duplicates`), standard practice is to add the modulo parameter before taking the modulo to prevent yielding a negative remainder: `(A - B + M) % M`.

## 🚀 Further Exploration
- If memory is extremely tight, the space complexity can be further optimized to $O(26) \approx O(1)$ by maintaining just a mapping of the counts each specific character has contributed, rather than a full size-$N$ DP array.
