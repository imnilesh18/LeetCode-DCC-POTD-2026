## 📌 Problem Statement

You are given an integer array `nums` and an integer `k`.

An integer `x` is **almost missing** from `nums` if `x` appears in **exactly one** subarray of size `k` within `nums`.

Return the **largest** almost missing integer from `nums`. If no such integer exists, return `-1`.

A **subarray** is a contiguous sequence of elements within an array.

---

## 🔒 Constraints

- `1 <= nums.length <= 50`
- `0 <= nums[i] <= 50`
- `1 <= k <= nums.length`

## 🧠 Approach

### Approach 1: Sliding Window + Frequency Hash Map (Brute Force / Simulation)
1. Maintain a sliding window of size `k` across `nums`.
2. For each window, collect all unique elements present inside it using a hash set.
3. For each unique element in the window, increment its count in an overall frequency hash map `mp` (representing how many size-`k` subarrays contain this element).
4. Iterate over `mp` and return the maximum element whose count is exactly `1`. If no such element exists, return `-1`.

### Approach 2: Case Analysis by Boundary Observation (Optimized)
By analyzing the subarray window properties, we can split the problem into 3 distinct cases:
1. **Case 1 (`k == n`):** There is only 1 subarray of size `k` (the entire array). Every element appears in exactly 1 subarray. The answer is simply the maximum element in `nums`.
2. **Case 2 (`k == 1`):** Subarrays of size 1 are just individual elements. A number appears in exactly 1 subarray if its total frequency in `nums` is `1`. We find the largest number with frequency `1`.
3. **Case 3 (`1 < k < n`):** Any interior element (elements at indices `1` to `n-2`) will always be part of at least 2 distinct subarrays of size `k`. Thus, only the boundary elements (`nums[0]` and `nums[n-1]`) can potentially belong to exactly one size-`k` subarray, provided their overall frequency in the entire array is `1`. We check if `nums[0]` or `nums[n-1]` have a global frequency of `1` and take the maximum.

## 💻 Solution Code

### Approach 1: Sliding Window

```cpp
// Intuition: Count how many subarrays of size k contain each unique number using a sliding window.
// Approach: Iterate through every window of size k, collect unique elements present in that window, update their frequency in a map, and return the maximum element with a count of 1.
// Time Complexity: O(n * k) - Traversing n - k + 1 windows and inserting up to k elements per window.
// Space Complexity: O(n) - Storing frequencies of elements in the hash map across windows.

class Solution {
public:
    int largestInteger(vector<int>& nums, int k) {
        int n = nums.size();

        int i = 0;
        int j = 0;

        unordered_map<int, int> mp; // Maps element to count of size-k subarrays containing it
        // I will go to each subarray of size k (window of size k) and mark which element came in that subarray
        // In the end, I will see which element came in exactly 1 subarray
        
        unordered_set<int> st;
        while(j < n) {
            if(j-i+1 == k) { // k sized subarray

                // Collect which elements are in this window
                for(int l = i; l <= j; l++) {
                    st.insert(nums[l]);
                }
                
                // Mark those elements
                for(int x : st) {
                    mp[x]++;
                }

                st.erase(nums[i]); // shifting window
                i++;
            }
            j++;
        }

        int result = -1;

        // Find the largest element which appeared in one subarray only
        for(auto [num, count] : mp) {
            if(count == 1 && num > result) {
                result = num;
            }
        }

        return result;
        
    }
};

/*
*
* Dry Run
*
* Input: nums = [3, 9, 2, 1, 7], k = 3
* 
* Window 1 [3, 9, 2] (i=0, j=2):
* - Unique elements: {3, 9, 2}
* - Update Map: mp[3]=1, mp[9]=1, mp[2]=1
* 
* Window 2 [9, 2, 1] (i=1, j=3):
* - Unique elements: {9, 2, 1}
* - Update Map: mp[9]=2, mp[2]=2, mp[1]=1
* 
* Window 3 [2, 1, 7] (i=2, j=4):
* - Unique elements: {2, 1, 7}
* - Update Map: mp[2]=3, mp[1]=2, mp[7]=1
* 
* Final Counts in mp: {3: 1, 9: 2, 2: 3, 1: 2, 7: 1}
* Elements with count == 1: 3, 7
* Max element with count == 1: 7
* Output: 7
*
*/
```

### Approach 2: Optimized Observation (Optimal)

```cpp
// Intuition: Analyze subarray coverage based on k. If k == n, pick maximum of entire array. If k == 1, pick max element with total frequency 1. If 1 < k < n, only boundary elements (nums[0] and nums[n-1]) can belong to exactly one subarray if they appear once globally.
// Approach: Handle three structural cases based on k and n using direct index checks and frequency counting.
// Time Complexity: O(n) - Single pass to count element frequencies.
// Space Complexity: O(1) - Fixed size array for elements up to value 50.

class Solution {
public:
    int largestInteger(vector<int>& nums, int k) {
        int n = nums.size();

        // case 1 : When k == n
        if(k == n) { // only one subarray possible. Select the largest element
            return *max_element(begin(nums), end(nums));
        }

        // case 2 : When k == 1
        int freq[51] = {0};
        for(int &num : nums) {
            freq[num]++;
        }

        if(k == 1) { // every index is one subarray. Find largest element which appears only once
            for(int num = 50; num >= 0; num--) {
                if(freq[num] == 1) {
                    return num;
                }
            }
            return -1;
        }

        // case 3 : 1 < k < n
        // Notice that only the first and last element are going to be the ones which will
        // appear only in one subarray. Others will be part of more than one subarray always
        
        int maxResult = -1;
        // So, if nums[0] appeared only at index 0, then it appeared only in one subarray
        if(freq[nums[0]] == 1) {
            maxResult = max(maxResult, nums[0]);
        }

        // Same, if nums[n-1] appeared only at index n-1, then it appeared only in one subarray
        if(freq[nums[n-1]] == 1) {
            maxResult = max(maxResult, nums[n-1]);
        }

        return maxResult;
    }
};

/*
*
* Dry Run
*
* Input: nums = [3, 9, 7, 2, 1, 7], k = 4
* n = 6
* k = 4, so Case 3 applies (1 < k < n)
* 
* Frequency table calculation:
* freq[1]=1, freq[2]=1, freq[3]=1, freq[7]=2, freq[9]=1
* 
* Check nums[0] = 3:
* freq[3] == 1 -> maxResult = max(-1, 3) = 3
* 
* Check nums[n-1] = nums[5] = 7:
* freq[7] == 2 (!= 1) -> maxResult remains 3
* 
* Return maxResult = 3
* Output: 3
*
*/
```

## 📝 Notes & Edge Cases

- **Small Constraints:** Values of `nums[i]` are constrained to `[0, 50]`, allowing an array-based frequency counter of size 51 for $O(1)$ space optimization.
- **Duplicate Elements in Window:** Using an `unordered_set` per window ensures an element is counted at most once per size-`k` subarray.
- **No Valid Integer:** Returns `-1` if no element satisfies the single-subarray condition.
- **Boundary Condition:** When `1 < k < n`, middle elements are guaranteed to sit in at least 2 distinct size-`k` windows, so checking `nums[0]` and `nums[n-1]` is sufficient.

---

## 💡 Key Insights

- **Mathematical Invariant:** An interior element at index $i$ ($0 < i < n-1$) participates in $\min(i+1, n-i, k, n-k+1)$ subarrays of size $k$. When $1 < k < n$, this count is strictly greater than 1.
- **Constant Time Evaluation:** By making this observation, we reduce the problem from $O(n \cdot k)$ sliding window tracking down to an $O(n)$ frequency count and $O(1)$ evaluation step.
